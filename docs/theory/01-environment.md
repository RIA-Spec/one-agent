# 1. Internal System as Environment

For an agent, an internal system is not primarily a set of commands or a manual — it is a continuously changing environment.

That environment usually includes, at the same time:

- Goals
- Constraints
- Roles
- Permissions
- State
- Rules
- Signals
- Means of intervention

So the fundamental question an agent faces is not "are there tools?" but:

- What is the current environment?
- What state is the current environment in?
- Which parts of the state can be observed?
- Which parts of the state can be changed?
- How will the environment respond after an action?

From this perspective, an agent's work inside an internal system is inherently both a cognitive problem and a control problem.
