# 7. Evidence and Evaluation

Inside an internal system, actions must not only happen — they must leave evidence; and the role of evaluation is not just post-hoc scoring, but judging whether the current understanding and behavior are actually effective.

Evidence matters because it makes behavior re-checkable, comparable, diagnosable, and correctable. Without evidence, mistakes can only be explained by impression; with evidence, a mistake can be located to the cognition, judgment, action, or evaluation stage.

Evaluation should at least answer:

- Was the goal actually achieved?
- Was the achievement surface-level compliance rather than substantive completion?
- Is the current method better than an alternative?
- At which layer did the failure mainly occur?

Evidence therefore provides the material for feedback, and evaluation provides the criteria. Without the former, feedback has nothing to work with; without the latter, feedback has no direction.
